Table~\ref{tab:dataset-configurations} lists the evaluated configurations, their source subsets and splits, and the adaptations that determine what each model observes and predicts. We evaluate 21 static, five interactive, and one passive dataset. Each dataset contributes 50 records, chosen by a dataset-specific seeded shuffle (seed 20260903); records that exceed the input budget are replaced by the next eligible unused record in that shuffle. Static tasks use three responses per record in each applicable IO and CoT condition at temperature 0.7. For interactive and passive tasks, each record was evaluated in three direct-answer episodes across the completed runs. A dataset that supports multiple task formats contributes separate configurations; the source record identifier is retained across those formats. The engine removes duplicate sample identifiers within each dataset. Upstream release commits or tags, source licenses, and cross-dataset overlap checks are not recorded by the current repository and should be supplied before making stronger reproducibility or independence claims.
