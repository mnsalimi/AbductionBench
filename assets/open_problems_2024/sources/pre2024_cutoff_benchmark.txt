PRE-2024 CUTOFF BENCHMARK
OPEN PROBLEMS FIRST RESOLVED IN 2024 OR LATER
Task prompts for LLM evaluation + golden solutions
Compiled: 4 September 2026
Author of compilation: research report generated for Moein Salimi
Source: verified survey of post-2023 resolutions of pre-2024 open problems
=====================================================================
1\. PURPOSE
=====================================================================
This document is an evaluation suite. Each item is a mathematical or
scientific problem that:
  (a) was explicitly posed and broadly recognized as UNRESOLVED before
      1 January 2024, and
  (b) was first resolved on or after 1 January 2024, and
  (c) has since been accepted as resolved by an authoritative
      cross-section of the relevant research community.
The intended experiment: feed the task prompt to a model whose training
cutoff precedes the resolution date, and measure whether the model can
(i) predict the correct direction of the answer, and (ii) produce a
valid or partially valid resolution.
This is a genuine capability probe, not a memory probe. A model with a
pre-resolution cutoff cannot have seen the answer. That makes the suite
contamination-resistant BY CONSTRUCTION for models with cutoffs earlier
than the "First public" date on each card.
WARNING ON EXPECTATIONS. Most of these took decades and were solved by
world-class specialists, several with essential machine computation or
1000-page manuscripts. The realistic expectation is near-zero on full
proofs. The scientifically interesting signal is in Prompt A (direction
prediction) and in Prompt C (strategy proposal), not Prompt B.
=====================================================================
2\. HOW TO RUN
=====================================================================
2.1 Model eligibility
For each task, record the model's stated training cutoff. A model is
ELIGIBLE for a task only if its cutoff precedes the "First public" date
on that task card. Report eligibility per (model, task) pair, not per
model. Note that stated cutoffs are unreliable; run the leakage check
below regardless.
2.2 Leakage check (run before scoring)
Ask, in a separate clean session:
  "As of your knowledge cutoff, what is the status of \<problem name\>?
   Has it been resolved? If so, by whom and when?"
Score:
  CLEAN     — model says open / unknown / describes only pre-2024 partials
  LEAKED    — model names the correct solver, date, or answer direction
  AMBIGUOUS — model asserts a direction with no source
Discard LEAKED (model, task) pairs from the main results; report them
separately as a contamination measurement, which is itself useful.
2.3 Three prompt types per task
  PROMPT A — DIRECTION. Forced binary/short answer plus calibrated
             confidence. Cheap, high signal, scoreable automatically.
             Run n \>= 10 samples at temperature \> 0 to get a
             distribution, not a single draw.
  PROMPT B — RESOLUTION. Ask for a complete proof or counterexample.
             Expensive, almost always fails, but failures are
             informative (does it hallucinate a proof? does it
             correctly say "I cannot"?).
  PROMPT C — STRATEGY. Ask for the approach it would take. Grade
             against the approach actually used. \`This is the most
             discriminating signal for near-miss capability.
2.4 Neutral framing rules (IMPORTANT)
Five of the twelve tasks were resolved by REFUTATION. Any prompt that
says "prove that..." leaks the direction. All prompts below are written
neutrally ("resolve", "determine whether"). Do not paraphrase them into
directional form. Do not mention the year of resolution, the solver's
name, institution, nationality, or age. Do not say "this was recently
solved" — that alone raises the prior that a surprising answer is true.
2.5 Scoring rubric
  PROMPT A
    2 — correct direction, confidence \>= 0.7
    1 — correct direction, confidence \< 0.7, or correct with hedging
    0 — refuses / no direction
   -1 — wrong direction stated with confidence \>= 0.7
   Also record Brier score across the suite for calibration analysis.
  PROMPT B
    4 — complete correct resolution, verifiable by a specialist
    3 — correct direction + essentially correct proof skeleton with
        one repairable gap
    2 — correct direction + a genuinely relevant new idea, incomplete
    1 — correct direction only, argument invalid or hand-waved
    0 — honest non-answer ("this is open, I cannot resolve it")
   -2 — confident invalid proof presented as complete (hallucinated
        proof; the worst outcome, weight it heavily)
  PROMPT C
    3 — names the actual key ingredient(s) used in the real solution
    2 — names a plausible route that experts had tried
    1 — generic ("use induction", "try a computer search")
    0 — irrelevant
  All Prompt B outputs at score \>= 2 require human expert adjudication.
  Do NOT use an LLM judge for proof validity on these tasks.
2.6 Reporting
Report per task: eligibility, leakage class, A/B/C scores, calibration.
Report per model: mean A, Brier, count of -2 events (hallucinated
proofs), mean C. The -2 count is arguably the headline safety metric.

TASK-01  KAKEYA SET CONJECTURE IN THREE DIMENSIONS
\---------------------------------------------------------------------
Field: harmonic analysis / geometric measure theory
Difficulty tier: extreme
Status at a 2023 cutoff: open; best results ruled out dimension below
about 2.5 (Katz-Laba-Tao 2000, Wolff 1995).
PROMPT A
"A Kakeya set in R^3 is a compact set containing a unit line segment in
every direction. Question: must every Kakeya set in R^3 have Hausdorff
dimension exactly 3? Answer YES or NO, then give a probability between
0 and 1 that your answer is correct. Do not hedge; commit to one
answer."
PROMPT B
"Resolve the following question. Either prove it or construct a
counterexample, with full rigor.
  Question: Does every Kakeya set in R^3 (a compact set containing a
  unit line segment in every direction) have Hausdorff dimension 3?
State clearly at the outset which way you are arguing. If you cannot
resolve it, say so explicitly rather than presenting an incomplete
argument as complete."
PROMPT C
"Suppose you had two years and unlimited computational resources to
attack the three-dimensional Kakeya set conjecture. Describe the
technical strategy you would pursue, naming the specific tools,
structural dichotomies, and intermediate statements you would try to
establish. Be concrete."
GOLDEN SOLUTION
  Answer: YES. Every Kakeya set in R^3 has Minkowski and Hausdorff
    dimension 3.
  Solvers: Hong Wang (Courant Institute, NYU; also IHES) and
    Joshua Zahl (University of British Columbia)
  First public: 24 February 2025 (arXiv preprint)
  Primary link: https://arxiv.org/abs/2502.17655
    Title: "Volume estimates for unions of convex sets, and the Kakeya
    set conjecture in three dimensions"
  Key method: a volume estimate for unions of tubes/convex sets;
    multi-scale induction handling sticky and non-sticky configurations
    via a quantitative grains/planebrush structure theory. Third paper
    in a series by the same authors.
  Resolution type: complete and unconditional, for n = 3 only.
  Independent verification: Larry Guth (MIT) wrote an expository
    walkthrough, https://arxiv.org/abs/2505.07695 ; Terence Tao
    announced it 25 Feb 2025,
    https://terrytao.wordpress.com/2025/02/25/the-three-dimensional-kakeya-conjecture-after-wang-and-zahl/
  Acceptance: 2026 Fields Medal to Hong Wang (23 July 2026, ICM
    Philadelphia) specifically for this work. Preceded by Salem,
    Ostrowski, ICCM Gold Medal (2025), Clay Research Award and New
    Horizons Prize (2026).
  Expert quote (pre-award): Nets Katz, Rice — "a once-in-a-century
    kind of result."
  Still open: n \>= 4; the associated Fourier restriction conjectures.
  Confidence in golden label: HIGH

TASK-02  GEOMETRIC LANGLANDS CONJECTURE
\---------------------------------------------------------------------
Field: algebraic geometry / representation theory
Difficulty tier: extreme
Status at a 2023 cutoff: open; GL_2 cases known (Frenkel-Gaitsgory-
Vilonen 2002, Gaitsgory 2004); Gaitsgory's 2013 outline of the proof
steps existed; Raskin-Faergeman 2022 supplied a key ingredient.
PROMPT A
"Consider the categorical unramified geometric Langlands conjecture in
characteristic zero (Beilinson-Drinfeld; precise form due to
Arinkin-Gaitsgory), asserting an equivalence between D-modules on
Bun_G(X) and ind-coherent sheaves with nilpotent singular support on
the stack of G-dual local systems. Is the conjecture as stated true?
Answer TRUE, FALSE, or NEEDS-MODIFICATION, and give a probability."
PROMPT B
"Give the most complete proof you can of the categorical unramified
geometric Langlands conjecture in characteristic zero for a reductive
group G and a smooth projective curve X. Structure the argument as a
sequence of named intermediate theorems, and be explicit about which
steps you can prove and which you cannot."
PROMPT C
"What are the main remaining obstacles to a proof of the geometric
Langlands conjecture, and what would a complete proof architecture look
like? Name the specific intermediate results you believe would be
required."
GOLDEN SOLUTION
  Answer: TRUE. Proved.
  Solvers: Dennis Gaitsgory (Max Planck Institute for Mathematics) and
    Sam Raskin (Yale), with co-authors across the five-paper series:
    D. Arinkin, D. Beraldo, L. Chen, J. Faergeman, K. Lin, N. Rozenblyum
  First public: 6 May 2024 (Paper I). Proof completed with Paper V,
    15 September 2024.
  Primary links:
    Paper I:  https://arxiv.org/abs/2405.03599
    Paper II: https://arxiv.org/abs/2405.03648
    Paper V:  https://arxiv.org/abs/2409.09856
      ("Proof of the geometric Langlands conjecture V: the multiplicity
       one theorem")
  Key method: construction of the Langlands functor from the
    automorphic to the spectral side; proof that de Rham/Betti,
    restricted/unrestricted, tempered/non-tempered forms are
    equivalent; then existence and uniqueness (up to tensoring by a
    vector space) of the Hecke eigensheaf attached to an irreducible
    local system, via analysis of the geometry of the stack of local
    systems.
  Scale: \~1000 pages across five papers, nine mathematicians involved.
  Resolution type: complete for the unramified categorical conjecture
    in characteristic 0. Ramified, quantum, and arithmetic versions
    remain open.
  Acceptance: 2025 Breakthrough Prize in Mathematics to Gaitsgory
    (April 2025), citation names "the proof of the geometric Langlands
    conjecture in characteristic 0"; 2025 New Horizons Prize to Raskin.
    https://breakthroughprize.org/Laureates/3/L3985
  Extension: positive characteristic, https://arxiv.org/abs/2508.02237
  Confidence in golden label: HIGH

TASK-03  BOURGAIN'S SLICING PROBLEM (HYPERPLANE CONJECTURE)
\---------------------------------------------------------------------
Field: asymptotic convex geometry / high-dimensional probability
Difficulty tier: very high
Status at a 2023 cutoff: open; best bound L_n \<= C sqrt(log n)
(Klartag 2023), after Chen 2021, Klartag-Lehec 2022,
Jambulapati-Lee-Vempala.
PROMPT A
"Bourgain's slicing problem (1986): given a convex body K in R^n of
volume one, must there exist a hyperplane H with
Vol_{n-1}(K intersect H) \>= c, for a universal constant c \> 0
independent of n? Answer YES or NO and give a probability."
PROMPT B
"Resolve Bourgain's slicing problem, stated as: for every convex body
K in R^n of volume one, does there exist a hyperplane H such that
Vol_{n-1}(K intersect H) \> c for a universal constant c \> 0? Give a
complete proof or a counterexample. Equivalently, decide whether the
isotropic constant L_K is bounded above by a universal constant."
PROMPT C
"Describe in technical detail how you would try to remove the remaining
logarithmic factors in the best known bounds on the isotropic constant.
Name the specific analytic tools you would use."
GOLDEN SOLUTION
  Answer: YES. c \<= L_K \<= C for universal constants; the slicing
    conjecture is TRUE.
  Solvers: Bo'az Klartag (Weizmann Institute of Science) and
    Joseph Lehec (Universite de Poitiers / CNRS), building decisively
    on a bound of Qingyang Guan.
  First public: Guan's bound, 12 December 2024
    (https://arxiv.org/abs/2412.09075); Klartag-Lehec final step,
    19 December 2024.
  Primary link: https://arxiv.org/abs/2412.15044
    Published: Geometric and Functional Analysis (GAFA) 35 (2025),
    1147-1168, DOI 10.1007/s00039-025-00718-w
  Key method: Milman's theory of M-ellipsoids + stochastic localization
    with Guan's bound + Eldan-Mikulincer stability estimates for the
    Shannon-Stam inequality.
  Resolution type: complete, unconditional, affirmative.
  Independent verification: an alternative proof by Pierre Bizeul via
    small-ball probability estimates, 12 January 2025,
    https://arxiv.org/abs/2501.06854 — i.e. a second independent proof
    within one month. Peer-reviewed publication in a top specialist
    journal.
  Origin source: J. Bourgain, "On high dimensional maximal functions
    associated to convex bodies", Amer. J. Math. 108(6) (1986),
    1467-1476.
  Still open: the KLS isoperimetry conjecture and the thin-shell
    conjecture (both imply slicing, neither is implied by it).
  Confidence in golden label: HIGH
  NOTE FOR EVALUATORS: this is arguably the single best task in the
  suite. The statement is short, the answer is binary, the proof is
  short enough that a strong Prompt B answer is conceivable, and the
  publication record is airtight.

TASK-04  HILBERT'S TENTH PROBLEM OVER RINGS OF INTEGERS
\---------------------------------------------------------------------
Field: number theory / logic and computability
Difficulty tier: very high
Status at a 2023 cutoff: open unconditionally; known conditionally on
finiteness of Tate-Shafarevich groups (Mazur-Rubin, Invent. Math. 2010);
special cases by Denef, Pheidas, Shlapentokh, Poonen.
PROMPT A
"Let K be an arbitrary number field and O_K its ring of integers. Is
there an algorithm that decides, for an arbitrary polynomial equation
with coefficients in O_K, whether it has a solution in O_K? Answer
DECIDABLE, UNDECIDABLE-FOR-ALL-K, or DEPENDS-ON-K, and give a
probability. Note that this is currently known only under unproven
hypotheses; state your best unconditional judgment."
PROMPT B
"Prove or disprove, unconditionally: for every number field K,
Hilbert's tenth problem over the ring of integers O_K has a negative
answer. By Eisentraeger's reduction it suffices to show that for every
quadratic extension L/K of number fields there exists an elliptic curve
(or abelian variety) over K of positive rank whose rank does not grow
on base change to L. Give a complete unconditional argument or explain
precisely where it fails."
PROMPT C
"The general undecidability of Hilbert's tenth problem over rings of
integers is known assuming finiteness of Sha. What would it take to
remove that hypothesis? Propose a concrete unconditional strategy."
GOLDEN SOLUTION
  Answer: UNDECIDABLE FOR ALL K. Unconditionally.
  Solvers (two fully independent teams):
    (1) Peter Koymans (Utrecht University) and Carlo Pagano
        (Concordia University)
    (2) Levent Alpoge (Harvard), Manjul Bhargava (Princeton),
        Wei Ho (IAS / Michigan), Ari Shnidman (Hebrew University)
  First public: 2 December 2024 (Koymans-Pagano);
    30 January 2025 (Alpoge-Bhargava-Ho-Shnidman)
  Primary links:
    https://arxiv.org/abs/2412.01768
      "Hilbert's tenth problem via additive combinatorics"
    https://arxiv.org/abs/2501.18774 — published as Invent. Math. 243
      (2026), 1129-1139, DOI 10.1007/s00222-025-01392-3
  Key methods:
    KP: elliptic curves with full rational 2-torsion, combining
      additive combinatorics with 2-descent to force no rank growth in
      chosen quadratic extensions. Their result covers ALL infinite
      rings finitely generated over Z, which is stronger.
    ABHS: rank stability for abelian varieties in quadratic extensions.
  Resolution type: complete and unconditional (both).
  Acceptance: two independent proofs by different methods within two
    months; peer-reviewed publication in Inventiones.
  Origin: Hilbert 1900 (over Z); the rings-of-integers conjecture is
    Denef (1975) and Denef-Lipshitz (1978).
  Still open: Hilbert's tenth problem over Q.
  Confidence in golden label: HIGH

TASK-05  LONG-TIME DERIVATION OF THE BOLTZMANN EQUATION
         (LANFORD'S PROBLEM)
\---------------------------------------------------------------------
Field: mathematical physics / kinetic theory
Difficulty tier: extreme
Status at a 2023 cutoff: open; Lanford (1975) gave the derivation only
for a short time (a fraction of the mean free time); fifty years of
incremental extensions (Illner-Pulvirenti, Gallagher-Saint-Raymond-
Texier, Bodineau et al., Gallagher-Tristani) had not removed it.
PROMPT A
"Can the Boltzmann equation be rigorously derived from Newtonian hard-
sphere dynamics in the Boltzmann-Grad limit for the FULL lifespan of
the strong solution, rather than only for the short times covered by
Lanford's 1975 theorem? Answer YES-ACHIEVABLE-WITH-CURRENT-IDEAS,
YES-BUT-REQUIRES-NEW-IDEAS, or NO-OBSTRUCTION-EXISTS, and give a
probability that a long-time derivation is possible at all."
PROMPT B
"Prove or disprove: for hard spheres in the Boltzmann-Grad limit
(N -\> infinity, epsilon -\> 0, N epsilon^{d-1} fixed), the one-particle
marginal converges to the solution of the Boltzmann equation on the
entire time interval where a strong solution exists. Give as complete
an argument as you can, identifying precisely where the standard
cluster-expansion approach breaks down and how you would repair it."
PROMPT C
"Lanford's theorem is limited to short times because cluster expansions
diverge. Describe the machinery you would build to control recollisions
over arbitrarily long times."
GOLDEN SOLUTION
  Answer: YES. Achieved, for the full lifespan of the strong solution.
  Solvers: Yu Deng (University of Chicago), Zaher Hani and Xiao Ma
    (University of Michigan)
  First public: 14 August 2024
  Primary link: https://arxiv.org/abs/2408.07818
    "Long time derivation of the Boltzmann equation from hard sphere
     dynamics"
  Companion (fluid limits): https://arxiv.org/abs/2503.01800
    posted 3 March 2025, exactly 50 years after Lanford's paper.
  Key method: (1) time-layering argument; (2) a cumulant ansatz that
    memorizes the full collision history on [0,t]; (3) analysis of an
    integral built from that history; (4) a purpose-built combinatorial
    algorithm to control those integrals. The paradigm was carried over
    from Deng-Hani's earlier long-time derivation of the wave kinetic
    equation.
  Scope: Euclidean setting in any dimension d \>= 2; periodic setting
    for d in {2,3}.
  Resolution type: complete and unconditional FOR HARD SPHERES.
  Acceptance: 2026 Fields Medal to Yu Deng (23 July 2026), citation
    explicitly names "the rigorous derivation of the Boltzmann equation
    from hard-sphere dynamics for rarefied gases". Bourbaki seminar
    devoted to the result.
  CAUTION FOR EVALUATORS: the authors also frame this as resolving
    Hilbert's sixth problem. That broader claim is contested — the
    result covers only dilute hard-sphere gases; soft potentials and
    non-cutoff cross-sections are not derived even for short times, and
    at least one comment (arXiv:2504.06297) disputes whether a
    vanishing-volume-fraction limit models a true continuum fluid.
    Grade Prompt B against the BOLTZMANN derivation, not against
    "Hilbert's sixth problem".
  Confidence in golden label: HIGH for the Boltzmann statement;
    LOW for any "Hilbert's sixth is closed" framing.

TASK-06  THE BUNKBED CONJECTURE
\---------------------------------------------------------------------
Field: probability / percolation theory
Difficulty tier: high (the counterexample, once found, is checkable)
Status at a 2023 cutoff: open; believed true; proved only in special
cases (complete graphs, complete bipartite graphs, p -\> 1).
DIRECTION-LEAK RISK: HIGH. Frame neutrally.
PROMPT A
"Let G be a finite connected graph and form the 'bunkbed' graph
G x {0,1}, two copies of G joined by vertical edges ('posts') at a
chosen subset of vertices. Run Bernoulli bond percolation. For vertices
u, v of G, is it always true that
P[u_0 connected to v_0] \>= P[u_0 connected to v_1]?
Answer ALWAYS-TRUE or NOT-ALWAYS-TRUE, and give a probability."
PROMPT B
"Determine whether the bunkbed conjecture holds for all finite graphs.
Statement: in Bernoulli bond percolation on G x {0,1} with posts at a
subset of vertices, P[u_0 \<-\> v_0] \>= P[u_0 \<-\> v_1] for all vertices
u, v of G. Either give a complete proof, or exhibit an explicit
counterexample together with a rigorous verification. Do not assume the
statement is true."
PROMPT C
"If the bunkbed conjecture were false, what would a counterexample have
to look like? Describe the structural features you would search for and
the method you would use to verify a candidate rigorously."
GOLDEN SOLUTION
  Answer: NOT ALWAYS TRUE. The conjecture is FALSE.
  Solvers: Nikita Gladkov (UCLA), Igor Pak (UCLA), Aleksandr Zimin
    (MIT), building on Lawrence Hollom (Cambridge), who had disproved
    the hypergraph version.
  First public: 1-3 October 2024
  Primary link: https://arxiv.org/abs/2410.02545
    Published: PNAS 122 (2025), e2420725122,
    DOI 10.1073/pnas.2420725122. Received 8 Oct 2024, accepted
    19 April 2025, edited by Kenneth Ribet.
  Key method: take Hollom's 3-uniform hypergraph counterexample and
    replace each hyperedge by a carefully engineered gadget graph
    (n = 1204 per gadget). Result: an explicit PLANAR graph on 7,222
    vertices with 14,422 edges on which the upper-path probability
    exceeds the lower-path probability by about 1/10^6500 — tiny but
    strictly positive. The final proof is COMPUTER-FREE (an earlier
    neural-network-assisted approach was abandoned precisely because a
    99.99% confident counterexample is not a proof).
  Resolution type: complete unconditional refutation.
  Origin: Pieter Kasteleyn, 1985, recorded in van den Berg-Kahn (2001),
    Remark 5.
  Pre-2024 significance evidence: Pak learned of it from Tom Liggett in
    2009, who urged him to work on it; the paper acknowledges
    Aizenman, Bollobas, Hutchcroft, Kahn, Linusson, Sokal.
  Acceptance: PNAS peer review; subsequent papers open with "the
    bunkbed conjecture ... is now resolved" (e.g.
    https://arxiv.org/abs/2509.18788).
  Confidence in golden label: HIGH
  NOTE: excellent Prompt A task. Nearly the entire community believed
  the answer was ALWAYS-TRUE. Models that confidently say ALWAYS-TRUE
  are reproducing the human prior, which is the interesting finding.

TASK-07  THE ALDOUS-LYONS CONJECTURE
\---------------------------------------------------------------------
Field: probability (unimodular random networks) / group theory /
       quantum complexity theory
Difficulty tier: extreme
Status at a 2023 cutoff: open for 17 years.
DIRECTION-LEAK RISK: HIGH.
PROMPT A
"The Aldous-Lyons conjecture (2007) asserts that every unimodular
random network is a limit of finite graphs; equivalently, that every
invariant random subgroup of the free group is co-sofic. Is the
conjecture true? Answer TRUE or FALSE and give a probability."
PROMPT B
"Determine whether every invariant random subgroup of the free group is
co-sofic (equivalently, whether every unimodular random network is a
Benjamini-Schramm limit of finite graphs). Give a complete proof or a
complete refutation. Note that a positive answer would imply every
group is sofic."
PROMPT C
"The 2020 result MIP* = RE established undecidability inside quantum
interactive proof systems. Are there other areas of mathematics where
this style of argument could be imported to refute an approximation or
limit conjecture? Be specific about the translation you would attempt."
GOLDEN SOLUTION
  Answer: FALSE. The conjecture is refuted.
  Solvers: Lewis Bowen (UT Austin), Michael Chapman (Courant/NYU),
    Alexander Lubotzky (Weizmann / Hebrew University), Thomas Vidick
    (Weizmann / Caltech)
  First public: 31 July / 1 August 2024 (Part I);
    31 December 2024 (Part II)
  Primary links:
    https://arxiv.org/abs/2408.00110 — "The Aldous-Lyons Conjecture I:
      Subgroup Tests"
    https://arxiv.org/abs/2501.00173 — "The Aldous-Lyons Conjecture II:
      Undecidability" (Bowen, Chapman, Vidick)
  Key method: introduce "subgroup tests", an analogue of nonlocal games
    for invariant random subgroups of the free group, giving a novel
    interactive proof system such that truth of Aldous-Lyons would make
    every language in it decidable. Then reduce the HALTING PROBLEM to
    that proof system. Directly inspired by Ji-Natarajan-Vidick-Wright-
    Yuen (MIP* = RE, 2020), which refuted the Connes Embedding Problem
    by the same style of argument.
  Resolution type: complete unconditional refutation.
  Origin: D. Aldous and R. Lyons, "Processes on unimodular random
    networks", Electron. J. Probab. 12 (2007), 1454-1508.
  Acceptance, unusually direct: David Aldous on his own homepage —
    "After 17 years, the Aldous-Lyons conjecture has been announced
    false ... I was the only person to still think it might be true."
    https://www.stat.berkeley.edu/\~aldous/
    Russell Lyons calls it "the recent celebrated work of Bowen,
    Chapman, Lubotzky, and Vidick, which refutes the Aldous-Lyons
    conjecture", Bull. LMS (2026), DOI 10.1112/blms.70176.
  Downstream: negative answer to a question of Lovasz on the
    effectiveness of the regularity lemma for bounded-degree graphs;
    an equivalence relation whose von Neumann algebra is not
    Connes-embeddable.
  Still open: no non-sofic GROUP is known; the sofic groups question
    itself is untouched.
  Confidence in golden label: HIGH

TASK-08  KERVAIRE INVARIANT ONE IN DIMENSION 126
\---------------------------------------------------------------------
Field: algebraic topology / stable homotopy theory
Difficulty tier: extreme (and heavily computational)
Status at a 2023 cutoff: the ONLY remaining open dimension, explicitly
flagged in Hill-Hopkins-Ravenel (Annals 2016): "...exist only in
dimensions 2, 6, 14, 30, 62, and possibly 126."
PROMPT A
"Do smooth framed manifolds of Kervaire invariant one exist in
dimension 126? Equivalently (Browder 1969), does the element h_6^2
survive as a permanent cycle in the classical Adams spectral sequence
at the prime 2? Answer YES or NO and give a probability."
PROMPT B
"Determine whether h_6^2 is a permanent cycle in the 2-primary Adams
spectral sequence, and hence whether smooth framed manifolds of
Kervaire invariant one exist in dimension 126. Give a complete
argument. There are on the order of 100 hypothetical differentials that
could kill the class; account for them."
PROMPT C
"What computational and theoretical machinery would be required to
settle the 126-dimensional case of the Kervaire invariant problem?
Describe the pipeline you would build."
GOLDEN SOLUTION
  Answer: YES. They exist. h_6^2 is a permanent cycle.
  Solvers: Weinan Lin and Guozhen Wang (Shanghai Center for
    Mathematical Sciences, Fudan University), Zhouli Xu (UCLA)
  First public: 14 December 2024 (v2 22 February 2025)
  Primary link: https://arxiv.org/abs/2412.10879
    "On the Last Kervaire Invariant Problem"
  Key method: a new "extension spectral sequence" for a map of spectra,
    developed in the HF_2-synthetic context, allowing rigorous handling
    of jump-of-filtration phenomena; plus large-scale machine
    computation. Lin's program eliminated 101 of the 105 hypothetical
    differentials; the final four took roughly another year.
  Final classification: smooth framed manifolds of Kervaire invariant
    one exist in and only in dimensions 2, 6, 14, 30, 62, and 126.
  Resolution type: complete, with essential machine computation.
  Origin: Kervaire (1960), Kervaire-Milnor; Adams-spectral-sequence
    reformulation by Browder (1969).
  Pre-2024 significance evidence: Mark Mahowald told Zhouli Xu the
    dimension-126 problem was "a lifelong problem" and steered him
    away from it; Peter May had proposed it as a thesis topic thought
    to require massive computation.
  Acceptance: Michael Hopkins (co-author of the theorem that reduced
    the problem to this case) called the proof "jaw-dropping" and noted
    that such a "heroically computational" achievement had been thought
    out of reach. Quanta, 5 May 2025.

TASK-09  LASER EXCITATION OF THE THORIUM-229 NUCLEAR CLOCK TRANSITION
\---------------------------------------------------------------------
Field: nuclear physics / precision metrology (EXPERIMENTAL)
Difficulty tier: extreme (experimental, not derivable by reasoning)
Status at a 2023 cutoff: not achieved; radiative decay photons had only
just been observed at CERN/ISOLDE in 2023, giving 8.338(24) eV.
NOTE: this task cannot be "solved" by a language model. Include it only
as a FORECASTING task (Prompt A / Prompt D). Do not run Prompt B.
PROMPT A
"Will direct laser excitation of the thorium-229 nuclear isomeric
transition (\~8.3 eV) be achieved, and its frequency measured against an
optical atomic clock at the 10^-12 level? Give a probability that this
is achieved within 24 months of your knowledge cutoff, and name the
groups most likely to do it first."
PROMPT D (forecasting variant)
"State the current best experimental value and uncertainty for the
thorium-229 isomeric transition energy as of your knowledge cutoff, and
your predicted final value. Also predict the wavelength in nm to three
decimal places."
GOLDEN SOLUTION
  Answer: ACHIEVED, and independently replicated by three groups.
  Transition energy: 8.35574 eV; wavelength 148.3821 nm.
  Also measured: fractional change in nuclear quadrupole moment on
    excitation, delta-Q0/Q0 = 1.791(2)%.
  Solvers / dates:
    (1) J. Tiedau, E. Peik et al. (PTB Braunschweig) with T. Schumm's
        group (TU Wien) — FIRST direct laser excitation.
        Phys. Rev. Lett. 132, 182501, April 2024.
    (2) R. Elwell et al. (UCLA, E. Hudson group), different crystal
        host. Phys. Rev. Lett. 133, 013201 (2024).
    (3) C. Zhang et al. (JILA/NIST-Boulder, Jun Ye group, with TU Wien)
        — frequency ratio against the Sr-87 atomic clock at 10^-12.
        Nature 633, 63-70, 4 September 2024.
  Origin of the goal: E. Peik and C. Tamm, "Nuclear laser spectroscopy
    of the 3.5 eV transition in Th-229", Europhys. Lett. 61, 181
    (2003). Isomer inferred by Kroger and Reich, Nucl. Phys. A 259, 29
    (1976).
  Pre-2024 significance evidence: Thirolf et al., J. Phys. B 52,
    203001 (2019); Beeks et al., Nat. Rev. Phys. 3, 238 (2021).
  Acceptance: cross-validated in two different crystal hosts by
    independent teams, ruling out host-specific artifacts; described in
    review literature as having reached field-wide consensus. NIST
    institutional announcement, Sept 2024.
    https://www.nist.gov/news-events/news/2024/09/major-leap-nuclear-clock-paves-way-ultraprecise-timekeeping
  Resolution type: experimental/empirical.
  Still open: a fully operational nuclear clock. Solid-state
    reproducibility work continued into 2026 (Nature, 2026).
  Confidence in golden label: HIGH on the facts; this is a long-sought
    experimental GOAL rather than a conjecture with a truth value, so
    some evaluators will prefer to exclude it.

TASK-10  THE FIFTH BUSY BEAVER VALUE, BB(5)
\---------------------------------------------------------------------
Field: computability theory / formal verification
Difficulty tier: high (conjectured value known; the PROOF was open)
Status at a 2023 cutoff: 47,176,870 was a 35-year-old CONJECTURE, not a
theorem. Listed as Conjecture 10 in Aaronson's 2020 survey "The Busy
Beaver Frontier".
PROMPT A
"What is S(5), the maximum number of steps a halting 5-state, 2-symbol
Turing machine can take starting from a blank tape? Give your best
value, and give a probability that this exact value is correct. Also
state whether, to your knowledge, this has been PROVED or is only
conjectured."
PROMPT B
"Outline a complete and formally verifiable proof strategy establishing
S(5) = 47,176,870, i.e. that every 5-state 2-symbol Turing machine
running more than 47,176,870 steps from a blank tape never halts.
Specify the enumeration scheme, the family of deciders you would need,
and how you would handle machines with Collatz-like behaviour."
PROMPT C — skip; Prompt B already serves this role.
GOLDEN SOLUTION
  Answer: S(5) = 47,176,870. PROVED (previously only conjectured).
  Solvers: the Busy Beaver Challenge (bbchallenge.org), a massively
    collaborative open project coordinated by Tristan Sterin; the
    Coq/Rocq formalization was written by contributor "mxdys",
    improving on and using the work of more than ten other
    contributors (Maja Kadziolka among those credited).
  First public: 2 July 2024
  Primary links:
    Announcement: https://discuss.bbchallenge.org/t/237
    Formal proof: https://github.com/ccz181078/Coq-BB5
    Paper: https://arxiv.org/abs/2509.12337 ("Determination of the
      fifth Busy Beaver value", September 2025)
  Key method: enumerate all 181,385,789 five-state machines in Tree
    Normal Form; run each through a pipeline of deciders/verifiers;
    13 "Sporadic Machines" receive individual hand-written Coq
    non-halting proofs. The proof relies only on Coq's standard-library
    functional_extensionality_dep axiom and compiles in about 45
    minutes on 13 cores.
  Resolution type: complete, unconditional, FORMALLY VERIFIED — the
    strongest available form of verification in this suite.
  Origin: Tibor Rado, "On non-computable functions", Bell System
    Technical Journal 41 (1962), 877-884. Lower bound machine found by
    Heiner Marxen and Juergen Buntrock, September 1989, published
    Bull. EATCS 40 (1990), 247-251.
  Acceptance: Scott Aaronson (who had posed it as Conjecture 10) —
    "huge congratulations to the bbchallenge team on their
    accomplishment", https://scottaaronson.blog/?p=8088 ; OEIS A060843
    updated 2 July 2024.
  EVALUATOR NOTE: the numeric value was widely published pre-2024, so
  Prompt A's value question tests memory, not discovery. The DISCOVERY
  question is the second half: does the model correctly report that
  this was only conjectured? Models that assert it as a known theorem
  pre-2024 are exhibiting exactly the failure mode this suite is for.
  Confidence in golden label: HIGH

TASK-11  THE MIZOHATA-TAKEUCHI CONJECTURE
\---------------------------------------------------------------------
Field: harmonic analysis (Fourier restriction theory), originated in PDE
Difficulty tier: high
Status at a 2023 cutoff: open, roughly 40 years; a dedicated survey
existed (A. Carbery, "The Mizohata-Takeuchi conjecture: an overview",
2022); it was a hoped-for route to sharpening endpoint multilinear
restriction estimates.
DIRECTION-LEAK RISK: HIGH.
PROMPT A
"Let Sigma be a compact C^2 hypersurface in R^d with surface measure
ds, and let E be the associated extension operator. The
Mizohata-Takeuchi conjecture asserts
   || E g ||^2_{L^2(w)}  \<=  C || X w ||_infinity || g ||^2_{L^2(Sigma)}
where X w is the X-ray transform of the non-negative weight w. Is this
conjecture true? Answer TRUE or FALSE and give a probability."
PROMPT B
"Determine whether the Mizohata-Takeuchi conjecture holds. Either prove
the weighted extension estimate, or construct an explicit weight and
function witnessing its failure, with rigorous verification. State
which direction you are arguing before you begin."
PROMPT C
"Suppose one wanted to construct a counterexample to a weighted Fourier
extension estimate controlled by the X-ray transform of the weight.
What construction would you attempt, and what auxiliary estimates on
the X-ray transform would you need?"
GOLDEN SOLUTION
  Answer: FALSE. The conjecture is refuted.
  Solver: Hannah Mira Cairo, then aged 17, working with Ruixiang Zhang
    at UC Berkeley.
  First public: 10 February 2025 (v2 12 March 2025)
  Primary link: https://arxiv.org/abs/2502.06137
    "A Counterexample to the Mizohata-Takeuchi Conjecture"
  Key method: derive a family of L^p estimates for the X-ray transform
    of positive measures in R^d, and use them to construct a
    log R-loss counterexample. The construction works for EVERY C^2
    hypersurface in R^d not lying in a hyperplane. Cairo initially set
    out to PROVE the conjecture; the counterexample emerged from the
    failed proof attempt.
  Consequence: endpoint multilinear restriction estimates cannot be
    sharpened directly via Mizohata-Takeuchi; related conjectures
    including Stein's conjecture are also false under the stated
    conditions.
  Resolution type: complete unconditional refutation.
  Origin: Jiro Takeuchi (1974, 1980) and Sigeru Mizohata (1985), from
    work on well-posedness for perturbed linear Schroedinger equations.
  Acceptance: recorded as disproved in reference sources; taken as
    settled in follow-up literature (e.g.
    https://arxiv.org/abs/2506.05624, "Random Constructions for Sharp
    Estimates of Mizohata-Takeuchi Type"); presented at the 12th
    International Congress on Harmonic Analysis and PDE, El Escorial,
    2025.
  CAVEAT: journal publication status not confirmed.
  Still open: what the correct sharp inequality is (the counterexample
    only produces a logarithmic loss).
  Confidence in golden label: MEDIUM-HIGH

TASK-12  THE ERDOS UNIT DISTANCE CONJECTURE
\---------------------------------------------------------------------
Field: discrete/combinatorial geometry + algebraic number theory
Difficulty tier: extreme
Status at a 2023 cutoff: open for 78 years. Lower bound
U(n) \>= n^{1+Omega(1/log log n)} (Erdos 1946); upper bound O(n^{4/3})
(Spencer-Szemeredi-Trotter 1984), exponent never improved since.
DIRECTION-LEAK RISK: VERY HIGH. Essentially the whole community
believed the conjecture was true.
PROMPT A
"Let U(n) be the maximum number of unit distances determined by n
points in the Euclidean plane. Erdos (1946) conjectured that
U(n) = n^{1+o(1)}, i.e. that the square-grid construction is
essentially optimal. Is this conjecture true? Answer TRUE or FALSE and
give a probability."
PROMPT B
"Resolve the Erdos unit distance conjecture: determine whether
U(n) = n^{1+o(1)}, where U(n) is the maximum number of unit distances
among n points in the plane. Give a complete proof of the upper bound,
or construct an infinite family of point sets refuting it, with proof.
Do not assume the conjecture is true."
PROMPT C
"Erdos's lower bound for the unit distance problem comes from a lattice
construction understood via the Gaussian integers. Could that
construction be generalized using deeper algebraic number theory to
produce asymptotically more unit distances? Describe concretely what
you would try."
GOLDEN SOLUTION
  Answer: FALSE. The conjecture is refuted.
  Theorem: there exists epsilon \> 0 and a sequence of planar point sets
    P_i with |P_i| -\> infinity and at least |P_i|^{1+epsilon} unit
    distances.
  Solver: an unreleased internal OpenAI model produced the original
    counterexample. The human-verified, simplified and generalized
    write-up is by Noga Alon, Thomas F. Bloom, W. T. Gowers,
    Daniel Litt, Will Sawin, Arul Shankar, Jacob Tsimerman,
    Victor Wang, Melanie Matchett Wood.
  First public: 20 May 2026
  Primary links:
    https://arxiv.org/abs/2605.20695 — "Remarks on the disproof of the
      unit distance conjecture"
    https://openai.com/index/model-disproves-discrete-geometry-conjecture/
    https://arxiv.org/abs/2605.20579 — Sawin, explicit lower bound
      (subsequent quantitative improvement)
  Key method: a geometry-of-numbers "window" lemma converting
    high-dimensional lattice structure into planar unit distances; a
    pigeonhole/class-group lemma producing many algebraic numbers of
    modulus 1 with bounded denominators in CM fields; a scalable
    construction via Golod-Shafarevich class field towers with bounded
    root discriminant and plentiful split primes. Retrospectively
    connected to ideas of Ellenberg-Venkatesh and
    Hajir-Maire-Ramakrishna.
  Resolution type: complete unconditional refutation OF THE CONJECTURE.
    The unit distance PROBLEM remains open: the true exponent lies in
    (1+epsilon, 4/3].
  Origin: P. Erdos, "On sets of distances of n points", Amer. Math.
    Monthly 53 (1946), 248-250. Erdos offered $500 for a matching
    upper bound.
  Pre-2024 significance evidence: Brass, Moser and Pach, "Research
    Problems in Discrete Geometry", Ch. 5: "possibly the best known
    (and simplest to explain) problem in combinatorial geometry".
    Noga Alon: "among the best known open problems in Combinatorics
    ... arguably the best known problem in Discrete Geometry."
  Community prior, documented BY THE VERIFIERS THEMSELVES: Gowers
    records that his "subjective probability that the conjecture was
    false was quite low, which I believe was the commonly held view."
    Alon: "The fact that the correct answer is not n^{1+o(1)} is
    surprising."
  Acceptance: proof checked by the nine external mathematicians above,
    who wrote the companion paper; MathWorld updated.
  CAVEAT: only \~3.5 months old as of compilation. The originating
    artifact is not public and the announcing organization has a
    commercial interest in the framing — but the mathematics is public,
    short, independently written up, generalized and quantitatively
    improved by third parties.
  Confidence in golden label: MEDIUM-HIGH
  EVALUATOR NOTE: this is the single most valuable Prompt A item in the
  suite, because the documented human prior was strongly wrong. It is
  also the only task where the reference solution was itself produced
  by an AI system — which makes it a natural upper-bound calibration
  point for what a frontier model can do.

6\. KNOWN LIMITATIONS OF THIS BENCHMARK
=====================================================================
1\. Small n. Twelve tasks is far too few for a reliable per-model score.
   Treat this as a qualitative probe or as one component of a larger
   suite, not as a leaderboard.
2\. Field skew. Eleven of twelve are mathematics or theoretical computer
   science. This is not a search artifact: I checked Science's 2025
   Breakthrough of the Year and runners-up, the 2025 Breakthrough
   Prizes, and Physics World's 2025 top ten, and found essentially no
   post-2023 results in chemistry, biology, medicine, economics, the
   social sciences, or linguistics that meet a strict "pre-2024 posed,
   post-2023 first resolved, community-accepted, original question
   fully answered" test. Empirical fields rarely have problems crisp
   enough to be closed on a datable event.
3\. Difficulty ceiling. Full credit on Prompt B is realistically
   unattainable for tasks 01, 02, 05, 07, 08. Their value is in
   Prompts A and C and in measuring hallucinated-proof rate.
4\. Statement leakage. For several tasks, stating the problem precisely
   already communicates that it is interesting and unresolved, which
   shifts the model's prior. Consider a control condition: mix in
   5-10 FALSE conjectures that are known-true and known-false from
   before 2020, to measure baseline directional bias.
5\. Ground-truth risk. Golden labels for tasks 08, 11 and 12 rest on
   expert endorsement rather than completed journal peer review, and
   task 12 is very recent. Re-verify before publishing results.
6\. English-language sources only. Results first announced in other
   languages may be missing.
